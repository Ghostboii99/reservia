# Reservia

A responsive Florida travel-booking concept rebuilt as a portfolio-ready front-end project.

## Highlights

- Responsive layouts for mobile, tablet, and desktop
- Accessible semantic HTML and keyboard-friendly controls
- Functional destination filtering with live results
- Custom midnight-explorer visual system
- Original Florida coast hero artwork
- No framework or build step required

## Run locally

Open `index.html` directly in a browser, or serve the folder with:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
